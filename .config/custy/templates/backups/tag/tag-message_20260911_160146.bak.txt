🛠️ Path Header Scanner v1.0.1 — Cleaner Scan Boundaries

Path Header Scanner v1.0.1 is a maintenance release that keeps dedicated
virtual environments outside recursive scans and improves repository
presentation.

### Highlights

- Ignore supported development, production, publishing, and auxiliary virtual
  environment directories during scanning.
- Align Git, Docker, formatter, and linter exclusions with that behavior.
- Add regression coverage for scan and tooling exclusions.
- Refresh README metadata and add a portable CLI preview.
- Standardize public project contact metadata.

Preview-first behavior, `--apply`, configuration, and dry-run safety are
unchanged.

### Release information

- Version: `v1.0.1`
- Previous version: `v1.0.0`
- Release type: patch
- Package compatibility: Python 3.11+
- Stability: stable
