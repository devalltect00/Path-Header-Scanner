# 🏷️ Project Badges

This document describes all badges used by Doc-Gen and their purpose.

## 📖 Documentation Strategy

Doc-Gen uses **MkDocs** for its own documentation because it is lightweight, simple, and easy to maintain.

For a centralized documentation portal that aggregates documentation from multiple projects, a separate project may use **Docusaurus**, which provides advanced features such as versioning, search, and multi-project documentation management.
